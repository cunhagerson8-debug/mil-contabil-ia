# MIL Contábil IA

**Uma solução da MIL Gestão & Tecnologia**

Plataforma inteligente para cálculos contábeis, gestão de folha de pagamento e consultoria tributária assistida por Inteligência Artificial.

## Funcionalidades

O MIL Contábil IA oferece um painel completo para gestão contábil com as seguintes funcionalidades:

| Módulo | Descrição |
|--------|-----------|
| Dashboard | Visão geral com indicadores de faturamento, folha e impostos |
| Fiscal e Contábil | Gestão de guias, impostos e obrigações fiscais com gráficos |
| Folha de Pagamento | Gestão de colaboradores, salários, INSS e FGTS |
| Notícias Contábeis | Feed de atualizações fiscais e trabalhistas |
| Calculadoras | Simples Nacional, INSS, IRRF e Pró-Labore |
| Assistente MIL IA | Chat inteligente com IA para consultoria contábil |

## Tecnologias

O projeto utiliza as seguintes tecnologias:

| Tecnologia | Versão | Finalidade |
|------------|--------|------------|
| React | 19.x | Framework de interface |
| TypeScript | 5.8 | Tipagem estática |
| Vite | 6.x | Build e dev server |
| Tailwind CSS | 3.4 | Estilização utilitária |
| Google Gemini | 2.0 Flash | Inteligência Artificial |
| Lucide React | 0.562 | Ícones SVG |

## Execução Local

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build de produção
npm run build
```

## Configuração da IA

Para utilizar o Assistente MIL IA, crie um arquivo `.env.local` na raiz do projeto:

```
GEMINI_API_KEY=sua_chave_aqui
```
